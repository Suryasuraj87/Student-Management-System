# Student Management System

A simple console-based Student Management System built using Python.

## Features

- Add a new student
- View all students
- Update student information
- Delete a student
- Search for a student
- Validate student age
- Prevent duplicate student names
- Store student data in a JSON file

## Technologies Used

- Python
- JSON
- File Handling
- Functions
- Lists and Dictionaries
- Loops
- Conditional Statements

## Student Information

The system stores the following information for each student:

- Name
- Age
- Course

## Data Storage

Student information is stored in a file named:

`students.json`

The program automatically loads existing student data when it starts and saves changes to the JSON file.

## How to Run

1. Make sure Python is installed on your computer.
2. Open the project in PyCharm or any Python-supported editor.
3. Run the `student_management.py` file.
4. Select an option from the menu.

## Menu Options

1. Add Student
2. View Students
3. Delete Student
4. Update Student
5. Search Student
6. Exit
